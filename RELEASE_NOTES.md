# CosmoNet Reader - Release v1.0.0 🚀

Siamo felici di annunciare la prima release stabile di **CosmoNet Reader** (v1.0.0)!
Un lettore PDF open source veloce, leggero e completamente senza pubblicità, pronto per Windows e Android.

## ✨ Funzionalità principali della v1.0.0
- 📄 **Lettura fluida**: Apri e leggi agevolmente qualsiasi PDF dal tuo dispositivo.
- 🕐 **Cronologia intelligente**: Accesso rapido agli ultimi 20 file recenti, con possibilità di rimozione veloce tramite swipe.
- 📖 **Navigazione comoda**: Muoviti tra le pagine con le frecce, la barra di avanzamento, o usa la funzione "Vai a pagina" toccando il contatore.
- 🔍 **Pinch-to-zoom accurato**: Ingrandisci e rimpicciolisci le pagine con i gesti nativi.
- 🌙 **Tema scuro nativo**: Interfaccia ottimizzata in modalità Dark con l'elegante branding CosmoNet.
- 📤 **Integrazione Android**: Apri i PDF direttamente da altre applicazioni usando la voce "Apri con...".

## 📦 Asset da scaricare
Qui sotto troverai i file di installazione. Scegli quello corretto per il tuo dispositivo:

### 🪟 Windows
Scarica il file di installazione per Windows (es. `CosmoNet_Reader_Installer.exe`).
Basta fare doppio clic sull'eseguibile e seguire la procedura guidata per avere l'app pronta all'uso!

### 📱 Android
Sono disponibili diversi file APK a seconda dell'architettura del tuo dispositivo. Per la maggior parte dei telefoni e tablet recenti, il primo è quello corretto:
- **`app-arm64-v8a-release.apk`**: Per la maggior parte dei dispositivi Android moderni (Consigliato).
- **`app-armeabi-v7a-release.apk`**: Per dispositivi Android meno recenti.
- **`app-x86_64-release.apk`**: Per emulatori o dispositivi specifici (x86_64).

> **Nota per l'installazione Android (Sideload)**: Per installare l'APK, assicurati di aver abilitato l'impostazione "Origini sconosciute" in Impostazioni → Sicurezza del tuo telefono.
